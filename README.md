# The World Today — Tuesday 17 November 2026

A one-page newspaper front page summing up the world's news of Tuesday
17 November 2026: 41 real stories from six continents, three illustrated
lead stories, and a world map with 16 numbered place pins.

`main.ts` draws the whole page pixel by pixel with the Node standard
library only (no network, no randomness, no timestamps), so every run
writes byte-identical output to `/output/entry.png` (1024x1024 PNG).

Run: `node main.ts`
